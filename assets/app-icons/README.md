# akilii platform icons

Original vector exported from Figma file KPWqp1q4FYiT2X2sYEw6yY, Foundations / App icon authority, node 4314:54988 on 5 September 2026. Artwork retained without redrawing. Forest #0E3A28 and paper #F7F2E8 derive from canonical tokens.

Rounded-square container is the requested platform adaptation: 1024 canvas, 64 outer inset, 896 square with 200 corner radius, 588 brandmark centred. Figma authority currently exports the bare mark; these container dimensions are an implementation choice, not an existing Figma component measurement.

Dark is the default desktop and browser icon. Light alternative included. ICO contains 16–256 PNG representations; ICNS contains 16–1024 representations. Rebuild with AKILII_SHARP pointing to installed sharp and `node tools/build-icons.cjs` from repository root. Repackage desktop after rebuilding icons. Existing installed copies do not update automatically.
